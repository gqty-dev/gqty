# Quickstart

To start using GQty, run `@gqty/cli` with your favourite packager.

<Alert
  className="space-top-5 space-bottom-3"
  severity="success"
  title="Even Quicker Start!"
>
  Run the following command with your endpoint as an argument to skip the
  interactive setup and jump right in!
</Alert>

<Tabs initialIndex={0}>
  <Tabs.Item label="npm">

```bash copy
> npx @gqty/cli
```

  </Tabs.Item>
  <Tabs.Item label="yarn">

```bash copy
> yarn dlx @gqty/cli
```

  </Tabs.Item>
  <Tabs.Item label="pnpm">

```bash copy
> pnpm dlx @gqty/cli
```

  </Tabs.Item>
</Tabs>

After the interactive setup, you should now see these files in your project:

```
.
├─ gqty
│ ├─ index.ts
│ └─ schema.generated.ts
└─ gqty.config.ts

```

You are all set! Head over to one of the following section to create your first
fetching component!
